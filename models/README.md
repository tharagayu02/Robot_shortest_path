# Computer Vision Model Directory

This directory stores object detection model definitions and pre-trained weights.

## Models Used

### 1. Ultralytics YOLOv8 Nano (`yolov8n.pt`)
- **Parameters**: 3.2M parameters
- **Target Hardware**: CPU inference optimized
- **Training Dataset**: COCO Dataset (80 object categories including bottle, book, chair, laptop, keys, cup, cell phone, etc.)
- **Auto-Download**: The application automatically downloads `yolov8n.pt` weights on initial run.
